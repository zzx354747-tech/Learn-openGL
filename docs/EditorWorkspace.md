# 编辑器工作区

运行：在项目的 `build` 目录执行 `./fbo_demo`。

## 操作

- 左侧 Scene hierarchy：搜索并选择当前场景中的物体，隐藏的物体也可选中。
- 中间 Scene view：实时渲染视口；点击表面选择物体。拖动左右分隔条可调整面板宽度，Layout 菜单可隐藏面板或恢复布局。
- 右侧 Inspector：编辑 Transform、显示状态及现有 Render / World 参数。
- `W / E / R`：鼠标释放时切换移动、旋转、缩放。也可使用视口上方的 Move / Rotate / Scale 按钮。
- World / Local：世界或局部坐标；缩放使用局部轴，避免引入剪切。
- Snap：移动步长 0.25，旋转步长 15°，缩放步长 0.1。
- 反引号键：捕获或释放相机；捕获后用 WASD、Space、Shift 移动。
- `8`：开关编辑覆盖层；输入文本或拖动手柄期间不会触发这个快捷键。

## 模型导入

将文件从 Finder 拖入中间视口或左侧 MODEL IMPORT 区；也可粘贴路径并点击 Import。
支持 GLB、glTF、OBJ、FBX、DAE、STL、PLY，实际解析由项目内的 Assimp 完成。
多文件逐个导入。导入失败时，将鼠标停留在错误提示或底部状态上查看详细原因。

导入后，模型自动进入当前场景、选中，并按视野和前方已有物体调整位置与尺寸。
模型轴心会居中；重复导入同一文件会复用网格和纹理，各实例拥有自己的变换。
几何、拾取、描边、前向渲染和阴影读取同一份 SceneObject 变换。
带外部材质的模型需保留配套文件和相对目录；glTF 的 .bin、OBJ 的 .mtl 和纹理应保持可访问。

首次解析及 GPU 上传在主线程执行，大模型可能短暂停顿；已加载的文件再次导入会使用缓存。
导入对象和变换可以通过 File 菜单保存并恢复。

## 场景保存与加载

视口顶部 File → Save scene / Load scene，按当前环境分别使用 `build/json/night.json`、`build/json/sunny.json`、`build/json/night_n8_3k.json`。
切换环境后点击 Save scene 保存该环境，点击 Load scene 恢复该环境的存档；切换本身不自动保存或加载。
保存由 `RendererScene` 读取实时状态，加载由同一对象负责重建资源和应用配置。

- 保存全部物体的 ID、名称、所属场景、变换、可见性、类型、球体材质编号及导入模型来源。
- 保存相机、灯光、全部渲染开关和参数、表面效果、场景状态，以及选中对象和 Gizmo 设置。
- 加载先解析和验证，再准备模型与环境贴图；准备失败保留当前场景。成功后替换物体集合，重设相机输入历史并清空等待导入的队列。
- 环境变化时重建环境/辐照度/预过滤贴图；恢复保存的灯光数值，不应用会覆盖自定义参数的环境预设。
- 保存通过同目录临时文件写入完成后替换，失败不截断之前的存档。

JSON 引用模型源文件，不打包模型、纹理或 HDR。导入模型使用绝对路径；手动填写的相对模型路径以存档目录为基准。
旧版内置球体/客厅存档仍可读取；旧版导入物体缺少模型来源时明确报错，需要重新保存。
GPU 句柄、帧缓冲和阴影矩阵由运行时构建/计算；窗口布局与窗口尺寸不属于场景存档。

## 依赖与验证

使用官方 ImGuizmo，源码固定在 `third_party/ImGuizmo`，来源提交和 MIT 许可随代码保留。
所有 UI 使用项目原有 Dear ImGui 上下文。未替换现有屏幕空间描边着色器和深度一致性修复。

可从 `build` 执行 `./fbo_demo --capture-ui /private/tmp/editor.ppm` 导出实际界面帧缓冲。


保存/恢复自动验证：在 `build` 执行 `./fbo_demo --check-scene-persistence`。
该验证创建真实 OpenGL 上下文，在独立临时目录测试导入模型、全部字段往返、环境重建、重复加载、加载后绘制、失败回滚和旧格式解析；不覆盖实际场景文件。
